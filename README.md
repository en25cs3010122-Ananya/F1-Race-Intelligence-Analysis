# Formula 1 Race Intelligence Analysis

## Project Overview
This project focuses on analyzing Formula 1 racing data to identify patterns, compare team and driver performance, study tyre strategies, and understand race reliability across seasons.

The project uses Tableau Public to transform racing data into interactive visualizations and dashboards.

## Objectives
- Analyze driver performance and championship points.
- Compare team performance across seasons.
- Examine driver and team wins and podiums.
- Analyze DNF (Did Not Finish) patterns and failure reasons.
- Explore tyre strategies and starting compounds.
- Identify countries hosting the most Grand Prix races.
- Study reliability trends across seasons.

## Tools and Technologies
- **Tableau Public:** Data visualization and dashboard creation.
- **Microsoft Excel:** Dataset handling and preprocessing.
- **GitHub:** Project documentation and version control.
